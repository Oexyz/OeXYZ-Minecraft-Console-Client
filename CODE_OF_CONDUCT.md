# Community code of conduct

OeXYZ contributors and users are expected to keep project spaces welcoming,
technical, and safe.

## Expected behavior

- Be respectful and assume good faith while discussing code.
- Give actionable feedback focused on behavior and evidence.
- Protect personal data, account details, server addresses, and security
  reports shared in confidence.
- Respect Minecraft server rules and the rights of server operators.
- Credit the work of contributors and third-party projects.

## Unacceptable behavior

Harassment, threats, hate speech, doxxing, sexualized conduct, deliberate
disruption, credential sharing, malware, spam, or instructions intended to
evade server enforcement are not accepted in project spaces.

Maintainers may edit or remove content and restrict participation when needed
to protect the community. Security-sensitive reports should be submitted
privately as described in `SECURITY.md`.
